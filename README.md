## 🔄 Как настроить облачное обновление на GitHub:
1. В вашем репозитории `https://github.com/gorelucovich/Super-SUS` откройте **Settings** и убедитесь, что репозиторий установлен как **Public (Публичный)**.
2. В файле `README.md` должна быть указана строка:
```
LATEST_APK_URL=https://litter.catbox.moe/i3quda.apk
```
3. При нажатии кнопки **«Облачное обновление» (📥)** в приложении оно считывает эту ссылку, скачивает APK с прогресс-баром и сразу запускает установку обновления!
