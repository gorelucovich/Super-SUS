## 🔄 Как работает облачное обновление внутри приложения:
Приложение **SusRadar** оснащено встроенной системой облачных обновлений (OTA).
Оно автоматически обращается к этому файлу `README.md` в репозитории:
`https://github.com/gorelucovich/Super-SUS/blob/main/README.md`

1. Когда вы вносите изменения в приложение, в этом файле обновляется строка `LATEST_APK_URL=https://...`
2. Пользователь внутри приложения нажимает кнопку **«Облачное обновление» (иконка облака со стрелкой 📥 в верхнем баре)**.
3. Приложение считывает актуальную ссылку на `.apk`, загружает его с отображением прогресс-бара и запускает автоматическое обновление без необходимости повторной ручной установки через браузер!

## ⚡ Возможности приложения:
* **Плавающий радар поверх Super Sus (HUD)**: перемещаемый оверлей с индикаторами фракций и шансов на Предателя/Джокера.
* **Распознавание речи войс-чата**: слушает собрание через микрофон и фиксирует алиби/обвинения.
* **Самообучающийся байесовский AI-движок**: послематчевая калибровка ролей и адаптация весов в локальной базе Room.
* **Журнал отладки (Debug 🐞)**: мгновенный экспорт логов `susradar_debug.log` и копирование в буфер обмена.
