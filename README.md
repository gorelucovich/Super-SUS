# SusRadar — AI Детектор ролей и Радар для Super Sus

**SusRadar** — тактический ассистент и дедуктивный радар для игры **Super Sus (Who Is The Impostor)**, работающий в реальном времени поверх игры и анализирующий события собрания, голосовой чат и действия игроков.

### Инструкция по установке на телефон:
1. Скачайте файл `.apk` на Android-устройство.
2. Откройте скачанный файл и нажмите **«Установить»** *(при необходимости разрешите установку из неизвестных источников в настройках устройства)*.
3. При первом запуске выдайте разрешение **«Отображение поверх других приложений»** (для работы плавающего оверлея поверх Super Sus) и доступ к **микрофону** (для распознавания голосового чата).

## ⚡ Основные возможности

### 1. Плавающий радар поверх игры (Floating HUD)
* Компактная плавающая иконка, свободно перемещаемая по экрану во время матча в Super Sus.
* Разворачиваемая карточка прямо поверх игры со статусом всех 10 игроков, вероятностями Предателя и предупреждениями.

### 2. Распознавание голосового чата
* Встроенный анализатор речи слушает голосовой чат собрания через микрофон.
* Автоматически извлекает упомянутые цвета игроков (*«Красный»*, *«Синий»*, *«Жёлтый»*...) и ключевые действия (*«в люке»*, *«визуал/скан»*, *«репорт»*, *«джокер»*).

### 3. Самообучающийся AI-движок (Adaptive Bayesian Engine)
* Автоматический расчет вероятностей для всех трёх фракций: **Космонавты**, **Предатели**, **Нейтралы**.
* **Послематчевая калибровка**: подтверждение реальных ролей после окончания матча обучает модель под стиль игроков вашего сервера.
* Хранение весов и истории матчей в локальной базе данных **Room**.

### 4. База знаний Super Sus
* Каталог всех ролей Космонавтов, Предателей и Нейтралов с тактиками контр-игры и маркерами детекции.
